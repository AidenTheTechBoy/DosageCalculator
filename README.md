# Dosage Calculator

Simple browser-based calculator for estimating a dose from body weight.

## What does it do?

- Converts weight from pounds to kilograms
- Calculates the target dosage in mg using `mg/kg`
- Calculates how many pills are needed based on pill size
- Rounds the pill count to the nearest quarter pill
- Shows the difference between expected and rounded dosage

## Inputs

- Weight in pounds
- Dosage in mg/kg
- Pill size in mg
